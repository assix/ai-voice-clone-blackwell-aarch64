# Input Reference Audio

This folder contains the source audio used for voice cloning.

## 📝 Instructions
1. **Format:** WAV (16-bit PCM recommended), 44.1kHz.
2. **Length:** 15-30 seconds is optimal.
3. **Content:** Clear speech with no background noise.

## 📂 Included Samples
* \`sample_english.wav\` - Neutral American English anchor.
* \`sample_french.wav\` - Standard Metropolitan French anchor.
* \`sample_arabic.wav\` - Lebanese Arabic anchor.

## 🚀 How to use your own voice
1. Record a file named \`my_voice.wav\`.
2. Place it in this folder.
3. Update the \`INPUT_FILE\` path in the python script (e.g., \`src/clone_english.py\`)."
